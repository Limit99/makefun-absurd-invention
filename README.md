A tiny, deterministic program for the make.fun competition
"One-Sentence Absurd Invention Pitch". It writes exactly one
sentence pitching a ridiculous invention to `/output/entry.txt`:

> The Regret Umbrella opens automatically over your phone whenever
> you start typing a message to your ex, and only folds away once
> you've shown it to a friend.

The program checks this competition's 1–220 character gate itself
before writing. No network, no randomness: every run produces the
same file.

Run it with Node: `node main.ts` (or set `OUTPUT_DIR`).
